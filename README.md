# Elm Kiosk

**AI-powered 3D kiosk application · Unity · 2026 · Client project**

Elm Kiosk is an interactive kiosk where visitors ask questions and get spoken answers from a 3D character. Each question is sent to a server that uses a large language model (LLM) to generate the answer, and the character then speaks it with synchronized lip movement.

## What I built

- **Interactive 3D character** that greets visitors and responds to their questions
- **Real-time server connection** over WebSockets to send questions and receive answers from the LLM backend
- **Voice playback with lip sync** using SALSA LipSync, so the character's mouth matches every answer
- **Kiosk-ready application** designed to run reliably on public-facing hardware

## Tech stack

Unity · C# · WebSockets · LLM integration · SALSA LipSync
